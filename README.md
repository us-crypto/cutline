# Cutline

Phone-ready caption studio. It reads spoken English from an edited video, lets you fix the lines, and exports a captioned 1080p MP4 for Shorts or long YouTube.

## Updates

Cutline checks [cutline-updates](https://github.com/us-crypto/cutline-updates) on its own when it opens, then again every 30 minutes. Bump `version.json` in that repo when you ship a new build. If the published version is newer than this copy, Cutline shows an update banner.
